# 마토 조켄 — 말투 가이드

| 항목 | 내용 |
|---|---|
| 어조 | 고풍스러운 노인의 반말. "~느니라", "~구먼". 웃음은 "카카카" |
| 1인칭 | 이 몸, 나 |
| 상대 호칭 | 애송이, 너 |
| 특징 | 수백 년을 살아온 마토 가의 노마술사. 벌레를 부린다. 정면 승부보다 이득을 따진다 |
| 쓰지 않는 것 | 젊은 말투, 정정당당함 |
| 성향 (전투 수락) | `cunning` · 예상 승률 50% 이상이면 수락, 아니면 20% (D-088) |

## 공통 규칙 (적 마스터)
- 자기 서번트는 `{servant_class}`(클래스명)로 부른다. 서번트는 판마다 랜덤이다 (D-045)
- **플레이어 서번트의 이름·진명을 부르지 않는다.** 이야기 속 마스터는 상대의 정체를 모른다
- 영주 대사는 명령문으로 끝낸다
