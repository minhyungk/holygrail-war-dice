# 제6차 성배전쟁 (가칭, `fsn6`)

페이트/스테이 나이트 세계관의 6차 성배전쟁을 다이스를 굴리는 TRPG식으로 즐기는 웹게임.
AI 에이전트와 개발자는 **`AGENTS.md`를 먼저 읽는다.**

## 실행
```
npm install
npm run dev        # 개발 서버
npm test           # 테스트 (데이터 검증, AGENTS.md 규칙 검사 포함)
npm run build      # 타입 검사 + 배포 빌드 (dist/)
npm run sim        # 서술 시뮬레이터 (시드 6, 선택 근거 출력)
npm run mockup     # 화면 목업 다시 빌드 → prototype/mockup/dist/
```

구조와 규칙은 [`docs/06-repo-structure.md`](docs/06-repo-structure.md).
