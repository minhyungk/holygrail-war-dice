# 구현 로드맵 [제안]
아래는 최초 단계별 계획이다. D-102에 따라 P2·P3를 함께 진행하고 P4 기능도 연결했다. 현재 구현 여부는 아래 현황을 기준으로 본다.
각 단계를 시작하기 전에 `open-questions.md`의 해당 구간을 모두 정리한다.

| 단계 | 내용 | 완료 기준 | 선행 질문 |
|---|---|---|---|
| P0 | 문서 확정(대상 시스템 한정), 프로젝트 스캐폴드 | 샘플 데이터가 스키마 검증을 통과하고, 잘못된 참조를 검출 | |
| P1 | 판정 엔진: 시드 RNG, 주사위, 스탯, 국면, 3국면 자동 전투, **이벤트 로그(서술 엔진 스키마 기준)**, 헤드리스 시뮬 | `dice.md`, `combat.md`, `phases.md` 예시가 테스트로 통과. 격차 최대에서도 약자 승률 > 0 | Q-101 ~ Q-107, Q-120 ~ Q-122, Q-52 |
| P2 | 화면 뼈대(메인 → 소환 → 전투 → 우승/패배), 강제 전투(토너먼트), 패배 빨리감기, VN 타이핑 출력, 서번트 7기 폴더(생성기로 만들기), 판 단위 동적 로딩, **서술 엔진 핵심(사실 수집·선택·조사 처리·정보 가림)** | 한 판을 끝까지 플레이 가능 (텍스트는 플레이스홀더 허용) | Q-11, Q-126, Q-127 |
| P3 | 낮·밤 루프, 5×5 맵, 조우, 스킬 43개 훅 연결 | 모든 스킬이 훅에 연결됨 (커버리지 리포트 0건) | Q-17, Q-31 ~ Q-34, Q-108 ~ Q-110, Q-123, Q-124 |
| P4 | 호감도(거부·배신), 마스터 로스터, 전투 후 선택, 적 AI (무작위 이동, 적끼리 전투, 영주 도주) | 처치/방면이 성향별 호감도에 반영. 적끼리 전투가 헤드리스로 돌아감 | Q-42, Q-43, Q-65 ~ Q-67, Q-111 ~ Q-113, Q-125 |
| P5 | 대사 채우기 (AI 초안 → 검수), 서술 엔진 도구(커버리지 시뮬레이터, 검증기, 미리보기), 기억·소문 대사 | 커버리지 리포트에서 생략된 상황 0건 | Q-50 |
| P6 | 서번트 확장 (14기 → 수백 기) | 신규 서번트를 **폴더 추가만으로** 등록 가능. 대사가 없는 태그는 클래스·공통 대사로 동작 | |
| P7 | AI 에필로그 (후순위, D-057) | 이벤트 로그 → 에필로그, 폴백 동작 | |

- 각 단계 끝: 문서와 코드를 대조하고 `decisions.md`를 갱신한다.
