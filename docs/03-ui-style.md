# 03. UI 스타일과 레이아웃

## 1. 디자인 방향 [확정]
- 분위기 키워드: 신비로움, 마법, 타입문, 깔끔함
- 레퍼런스: 페이트 스테이 나이트, FGO (원작 VN 스타일 전체화면 텍스트)
- 다이스 애니메이션: 실제로 다이스를 던지는 느낌이 나야 한다
- 라이트/다크 모드: 지원하지 않음

## 2. 컬러 토큰 [임시값] (D-046)
**코드에서 색을 직접 쓰지 않고 토큰만 쓴다.** 아래 값은 AI가 정한 임시값이며 나중에 바꾼다. 방향: 어두운 남색 바탕 + 금색 강조 (마법진·영주 느낌).

| 토큰 | 용도 | 값 |
|---|---|---|
| `--bg-base` | 전체 배경 | `#0E1220` |
| `--bg-panel` | 패널/카드 배경 | `#171C2E` |
| `--bg-textbox` | VN 텍스트박스 | `#0B0E18` (불투명도 88%) |
| `--text-primary` | 본문 | `#ECE6D6` |
| `--text-muted` | 보조 | `#9A97A6` |
| `--accent` | 강조/선택 | `#C9A45C` |
| `--danger` | 위기/위험 | `#C0392B` |
| `--miracle` | 잭팟(기적) 연출 | `#F4D77A` |
| `--cond-full` `--cond-hurt` `--cond-danger` | 상태 3단계 색 | `#5FAF7A` `#D9A441` `#C0392B` |
| `--class-saber` `--class-archer` `--class-lancer` `--class-rider` `--class-caster` `--class-assassin` `--class-berserker` | 클래스 색 (7종) | `#3D74D9` `#C8452F` `#1FA38A` `#D3558F` `#8A5CD6` `#6B7385` `#8E2230` |
| `--affinity-hostile` `--affinity-wary` `--affinity-neutral` `--affinity-friendly` `--affinity-loyal` | 호감도 5단계 색 (`systems/affinity.md` 기준) | `#B03A3A` `#C9803A` `#9A97A6` `#6FA8DC` `#C9A45C` |

## 5. 레이아웃
### PC [제안]
```
+--------------------------------+------------+
|                                |  사이드     |
|            맵 (타일)            |  패널       |
|                                | (상태/로그) |
+--------------------------------+------------+
|         VN 텍스트박스 (전투/대화 시)          |
+---------------------------------------------+
```
### 모바일 [제안]
- 맵: 전체화면, 하단 시트로 행동 메뉴
- 전투/대화: 전체화면 텍스트 오버레이, 탭으로 진행
- 로그: 별도 시트

## 6. VN 텍스트 출력 규격 [임시값] (D-046)
타이핑 출력 방식은 [확정]. 아래 값은 임시값이며 나중에 조정한다.
| 항목 | 값 | 상태 |
|---|---|---|
| 글자당 출력 간격 | 30ms (느림 50 / 보통 30 / 빠름 15) | [임시값] |
| 탭/클릭 동작 | 출력 중 = 즉시 완성 / 완성 후 = 다음 | [임시값] |
| 자동 진행 옵션 | 있음, 기본 꺼짐. 켜면 완성 후 1.5초 뒤 다음 | [임시값] |
| 속도 설정 | 3단계 (느림/보통/빠름) | [임시값] |
| 화자 표시 | **표시함** [확정] D-046. 위치: 텍스트박스 좌상단 | 위치 [임시값] |
| 스킬 발동 텍스트 강조 방식 | 스킬 이름을 `--accent` 색 + 굵게 | [임시값] |
| 기적(잭팟) 연출 | 다이스가 `--miracle` 색으로 빛남 + 화면 테두리 번쩍임 | [임시값] |
