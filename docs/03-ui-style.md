# 03. UI 스타일과 레이아웃

## 1. 디자인 방향 [확정]
- 분위기 키워드: 신비로움, 마법, 타입문, 깔끔함
- 레퍼런스: 페이트 스테이 나이트, FGO (원작 VN 스타일 전체화면 텍스트)
- 다이스 애니메이션: 실제로 다이스를 던지는 느낌이 나야 한다
- 라이트/다크 모드: 지원하지 않음

## 9. 판정·텍스트 표시 [확정] (D-137)
- 정보 2단계 전에는 적의 스탯 랭크와 개별 스탯 수치를 함께 가린다. 숨긴 수치를 중간 합산 애니메이션으로도 드러내지 않는다. 주사위·기적·최종 판정값은 판정 확인을 위해 표시한다.
- 조우 도주와 전투 중 일반 도주 모두 플레이어의 굴림 → 양측 판정값 → 도주 성공/실패 순서로 보여 준다. 적이 도주할 때는 추격 결과로 표시한다. 동점은 도주한 쪽의 성공이다.
- 행동·도주 판정 결과의 기본 표시 시간은 `text.roll_result_ms`(1100ms, 기존 값)이다.
- 재굴림을 거절해 이미 보여 준 결과는 해당 판정에서만 재사용한다. 다음 판정은 새로 표시한다.
- VN은 최근 60줄을 보관한다 (`text.vn_keep`, 기존 값 유지). 새 줄이 오면 로그 길이와 관계없이 타이핑을 처음부터 시작한다. 같은 본문이 연속돼도 각각 새 줄이다.
- 위험에서 멈춘 상태는 위험으로 표시한다. 실제로 쓰러졌을 때만 전투 불능으로 표시한다.
- 판정이 있는 행동은 도입 나레이션 → 주사위(실패 시 재굴림 선택 포함) → 결과 순서다. 도입은 `action_started` 비트가 맡아 재굴림 질문보다 먼저 나온다 (D-141).
- 낮 행동 판정 상자는 머리에 운명점을 두고, 넓은 화면에서는 트레이와 판정 카드를 나란히 놓아 스크롤 없이 재굴림 선택까지 보이게 한다. 전투 화면 내 프로필에도 운명점을 따로 표시한다 (D-141).
- 판정이 있는 행동(마력 공급·교류·정보 수집·제작)의 결과는 주사위와 합산을 다 보여 준 뒤에 마력·호감도 막대에 반영한다. 던지기 전에 막대가 먼저 움직이지 않는다 (D-140).
- 맵 화면의 마력·호감도 막대는 사이드 패널의 서번트 프로필 아래에 둔다. 사이드 패널이 없는 좁은 화면(900px 미만)에서는 상단 HUD에 둔다 (D-140).

## 전투 예상 승률 [확정] (D-139, D-140)
조우 선택과 전투 화면에 예상 **승/패** 비율만 표시한다 (무승부·퇴각은 세지 않음, 합 100%). 국면과 개입 뒤 갱신한다. 추가 자원 사용 없이 계속 싸우는 기준의 추정치이며 적 AI 행동을 반영한다 (`systems/combat.md` §9).
- 조우: 선택지 바로 위에 승/패 막대
- 전투: 상단 국면 이름 아래 한 줄 승/패 막대 (카드·주사위 영역을 밀어내지 않는다)
- 기준·오차 설명 문구는 표시하지 않는다 (D-141)
