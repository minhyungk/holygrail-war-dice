## 1. 격자와 좌표 [확정: 5×5] (D-048)
- 좌표는 `(행, 열)`, 1부터 시작. 1행이 이미지 위쪽(바다, 북쪽).
- 타일 ID [제안]: `tl_r{행}c{열}` (예: `tl_r3c3`)
- 인접: **상하좌우 4방향** [확정] (D-073). 대각선은 인접이 아니다

## 4. 중앙 타일 [확정] (D-073)
`(3,3)` 공원 녹지. 강제 전투 장소 (`systems/combat.md` §7). 개활지라 정면 격돌이 많이 나온다.

## 5. 시작 위치 [임시값] (D-109)
 모든 진영이 서로 다른 타일에서 시작, 중앙 타일 제외, 시드 RNG로 배정.

## 6. 미정 사항
- 지형 분류 확인, 장소 이름
- 인접은 상하좌우로 확정. 강 건너기 제한은 현재 없음
- 랜드마크 타일의 특수 효과 여부
- 칸 역할은 tiles.json의 role로 지정. 밤을 마친 칸의 역할이 다음 날 보너스 (정보 → 정보 수집, 교류 → 교류, 영맥 → 아침 마력 공급, D-145). 영맥 칸은 진지작성 스킬의 전투 보정 조건이기도 하다 (D-146)
