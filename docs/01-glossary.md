# 01. 용어 사전
같은 단어는 항상 같은 뜻으로 쓴다. 다른 문서에서 용어를 재정의하지 않는다.
용어를 추가할 때는 이 표에만 추가하고 다른 문서는 이 표를 참조한다.

## 1. 진영과 인물
| 용어 | ID/코드명 | 정의 | 상태 |
|---|---|---|---|
| 마스터 | `master` | 서번트를 소환한 인간. 플레이어와 적 진영 모두 해당 | [확정] |
| 서번트 | `servant` | 마스터가 소환한 영령 | [확정] |
| 진영 | `faction` | 마스터 + 서번트 한 쌍 | [확정] |
| 적 AI | `enemy_ai` | 플레이어가 아닌 진영의 행동 로직. 무작위 이동, 적끼리 3국면 자동 전투, 위험 시 영주 도주 | [확정] D-051 |

## 2. 판정
| 용어 | ID/코드명 | 정의 | 상태 |
|---|---|---|---|
| 판정 | `roll` | 2d10 + 보정치. 대항 판정과 단독(DC) 판정이 있음 | [확정] D-015 |
| 잭팟(기적) | `miracle` | 자연값이 행운별 구간에 들어오면 발동. 판정 +5 | [확정] D-036 |
| 운명점 | `fate_point` | 재굴림에 쓰는 자원. 초기 3, 게임 중 회복 없음 | [확정] D-038 |

## 3. 전투
| 용어 | ID/코드명 | 정의 | 상태 |
|---|---|---|---|
| 국면 | `phase` | 전투 중 승부가 갈리는 한 장면의 유형. 유형마다 쓰는 스탯이 다름 | [확정] |
| 상태 | `condition` | 서번트 체력의 3단계 표기: 만전 / 부상 / 위험 | [확정] D-014 |
| 개입 지점 | `intervention` | 자동 전투 중 유저에게 선택권이 넘어오는 순간 | [확정] |
| 영주 | `command_seal` | 마스터의 절대 명령권. 3획, 회복 없음. 보구 즉시 발동 / 버프 / 도주 / 배신 저지 | [확정] D-023, D-041 |
| 보구 | `noble_phantasm` | 서번트의 보구. 스킬 데이터에서 kind로 구분 | [확정] |
| 강제 전투 | `final_battle` | 7일차 종료 시 남은 진영을 중앙 타일에 모아 치르는 토너먼트 전투 | [확정] D-025, D-027 |
| 처치 / 방면 | `execute` / `release` | 전투 후 패배한 상대 마스터에 대한 선택 | [확정] D-020 |
| 태세 | `stance` | 전투 전 마스터가 정하는 방침 (공세/신중 등) | [제안] |

## 4. 스킬
| 용어 | ID/코드명 | 정의 | 상태 |
|---|---|---|---|
| 훅 | `hook` | 스킬이 끼어들 수 있는 게임 내 순간. 엔진 코드가 정의하는 고정 목록 | [확정] |
| 스킬 | `skill` | 훅 + 조건 + 효과 + 텍스트로 이루어진 자동 발동 규칙 | [확정] |
| 범용 스킬 | `generic` | 여러 서번트가 랭크만 달리해 공유하는 스킬 (천리안, 기승 등) | [확정] |
| 고유 스킬 | `unique` | 서번트 개별 스킬. 효과를 개별 지정 | [확정] |

## 5. 낮 루프와 관계
| 용어 | ID/코드명 | 정의 | 상태 |
|---|---|---|---|
| 낮 | `day_phase` | 행동 3회. 정보 수집, 제작, 마력 공급, 교류, 이동 | [확정] D-048 |
| 밤 | `night_phase` | 행동 3회. 행동 종류 [TBD] | [확정] D-048 |
| 조우 | `encounter` | 타 진영과 같은 타일에서 마주치는 순간 | [확정] |
| 마력 | `mana` | 서번트가 가진 자원(최대 100). 보구 개방에 소모 | [확정] |
| 호감도 | `affinity` | 플레이어와 자기 서번트 사이의 관계 수치. 5단계로 표시 | [확정] D-021, D-029 |
| 성향 | `alignment` | 서번트의 선 / 중립 / 악. 처치·방면 시 호감도 변동 방향을 정함 | [확정] D-056 |
| 명령 거부 | `refusal` | 호감도 경계·적대에서 서번트가 확률적으로 명령을 거부 | [확정] D-055 |
| 배신 | `betrayal` | 호감도 적대에서 서번트가 확률적으로 배신. 영주로 저지 가능 | [확정] D-055 |
| 에필로그 | `epilogue` | 우승 후 AI가 이벤트 로그로 쓰는 소설식 결말 | [확정] |
