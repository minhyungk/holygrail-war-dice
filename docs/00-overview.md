# 00. 개요

## 1. 한 줄 컨셉 [확정]
페이트/스테이 나이트 세계관의 **6차 성배전쟁**을, 다이스를 굴리는 TRPG식으로 즐기는 웹게임. 플레이어는 마스터 1명이며 서번트와 함께 성배전쟁을 치른다.

## 2. 설계 기둥 [확정]
판단이 갈릴 때 이 순서로 우선한다.
1. **텍스트가 재미의 중심이다.** 상황별 대사, 마스터·서번트 간 대화, 원작과 다르게 흘러가는 전개.
2. **마스터는 실시간으로 지시하지 않는다.** 전투는 서번트가 자동 진행하고, 핵심 순간에만 마스터가 개입한다.
3. **주사위가 이변을 만든다.** 어떤 격차에서도 승률 0%가 없다.
4. **스킬은 텍스트가 나오는 계기다.** 조건이 맞으면 자동 발동하고 그때 텍스트가 출력된다.
5. **결정론 우선.** 텍스트는 사전 작성이 기본이고 AI는 최소한으로 쓴다.
6. **모든 판정 수치(threshold)는 한 곳에 모은다.** `constants` 데이터에만 두고 코드는 import해서 쓴다 (`04-data-schema.md`).
7. 외국어 구현을 염두에 두고 있으므로 언어 교체가 편하도록 하드코딩 지양, 언어팩 교체가 용이해야함. 

## 3. 한 판의 흐름 (요약)
```
메인 → 소환(랜덤/촉매) → [1~7일차 반복: 낮 행동 3회 → 밤 행동 3회 (조우 → 3국면 전투 → 처치/방면)]
     → 7일차 밤 종료 시 남은 진영 강제 전투(토너먼트) → 우승(에필로그) / 패배(빨리감기로 결말 확인)
```
- 적 진영은 무작위로 움직이고 서로 싸운다 (`systems/day-loop.md` §7).
- 시작 서번트 데이터: `content/servants-5th.md`. 맵: `content/map-fuyuki.md`.
- 상세 전이는 `02-screens-flow.md`.

## 4. 범위
### 포함 [확정]
- 5차 성배전쟁 서번트 7기로 시작: 알트리아 펜드래곤, 쿠 훌린, 에미야, 메데이아, 사사키 코지로, 헤라클레스, 메두사. 이후 14기 등으로 확장
- 랜덤 소환 / 촉매 소환
- 정보 수집, 마력 공급, 서번트 교류, 이동, 조우, 전투
- 적 마스터: 타입문 캐릭터 (키리츠구, 올가마리 등)
- 전투 후 처치 / 방면
- 적 진영 AI (자율 이동, 적끼리 전투)
- VN식 타이핑 텍스트 출력
- AI 에필로그 (우승 후 소설식 결말). 구현 후순위 (D-057)

### 비포함 [확정]
- 물리 엔진, 실시간 전투
- 턴마다 커맨드를 고르는 전투 (자동 진행 + 개입 지점으로 대체)
- AI가 판정하거나 결과를 결정하는 것
- 폐기된 시스템: 포섭, 평판 (D-020), 사건, 연합 (D-024), 진영 호감도 (D-029), 방심 (D-037)

### 나중에
- 다대일 전투
- 서번트 풀 확장 (로드맵 P6)
- 플레이어 마스터 커스터마이즈 (D-057)

## 5. 레거시와의 관계 [확정]
기존 "성배전쟁 시뮬레이션"은 레거시로 유지하며, 이 프로젝트와 코드를 공유하지 않는다. 필요한 데이터·수치·스크립트만 사용자가 선별해 가져온다. 가져온 자산의 목록과 주의사항은 `05-legacy.md`.

## 6. 플랫폼 [확정]
