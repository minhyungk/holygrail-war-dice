# 호감도와 전투 후 선택
상태: 구조·단계·거부/배신 확률 [확정], 변동량·계수 [임시값] (D-109) · 관련: dice.md, mana.md, combat.md, text.md · constants 접두: `affinity.`

## 1. 목적
플레이어와 자기 서번트의 유대를 수치로 관리하고, 판정 보정·명령 거부·배신·전투 후 선택에 반영한다.
호감도 단계 정의는 이 문서가 기준이다 (D-021).

## 2. 입력 / 출력 / 상태
- 입력: 전투 후 선택, 낮 교류, 마력 공급 결과, 전투 중 행동
- 출력: 호감도 수치·단계, 판정 보정, 명령 거부, 배신
- 상태: 서번트 호감도 (0 ~ 100)

## 3. 규칙
### 3.1 종류 [확정] (D-029)
서번트 호감도 1종 (플레이어 ↔ 자기 서번트).

### 3.2 단계 [확정] (D-021, D-054) → `affinity.thresholds` = [10, 30, 50, 80]
경계값은 **하한 포함, 상한 미포함**.
| 단계 | 범위 |
|---|---|
| 적대 | 0 ≤ x < 10 |
| 경계 | 10 ≤ x < 30 |
| 중립 | 30 ≤ x < 50 |
| 호감 | 50 ≤ x < 80 |
| 충성 | 80 ≤ x ≤ 100 |

### 3.3 초기값과 변동
1. 초기값: 레거시 성격별 초기값(25~55) [확정] (D-073). 예: 알트리아(royal) 35
2. 변동 후 값 = 현재값 + 요인별 고정값 × 서번트 증감 계수, 반올림 후 0~100으로 절삭. 값은 D-109 [임시값] → `affinity.delta_*`
| 요인 | 방향 | 상태 |
|---|---|---|
| 처치 / 방면 | §3.5 | [확정] |
| 마력 공급 결과 | `mana.md` §3.4 | [확정] |
| 낮 교류 | 성공 +5 / 실패 -3, 성격 계수 적용 | [임시값] D-109 |
| 전투 중 행동 | [TBD] | 요인 [확정] |

### 3.4 게임에 미치는 영향 [확정] (D-055)
1. 판정 보정 → `affinity.roll_mod`
   | 단계 | 적대 | 경계 | 중립 | 호감 | 충성 |
   |---|---|---|---|---|---|
   | 보정 | -2 | -1 | 0 | +1 | +2 |
   - 적용 범위: 플레이어 서번트의 모든 판정 (전투 국면, 낮 타일 역할, 기습·도주, 마력 공급). D-109
2. **명령 거부**: `경계`, `적대`에서 확률적으로 명령을 거부한다
   - 확률 [확정] (D-073) → `affinity.refusal_chance`: 적대 40%, 경계 15%
   - 거부할 수 있는 명령 [확정] (D-083): **도주, 타일 이동(거부 시 무작위 이동), 전투 개시 여부**. 영주 명령은 거부 불가 (D-109)
3. **배신**: `적대`에서 확률적으로 배신한다. **영주 1획으로 저지할 수 있다**
   - 확률 [확정] (D-073) → `affinity.betrayal_chance`: 적대 40%
   - 판정 시점 [확정] (D-073): 매일 밤이 끝날 때 1회
   - 배신 결과: 마스터가 **서번트에게 살해당하고 패배** [확정] (D-108)

### 3.5 전투 후 선택: 처치 / 방면 [확정] (D-020, D-056)
서번트 성향(선/중립/악)에 따라 호감도가 변한다.
| 서번트 성향 | 방면 | 처치 |
|---|---|---|
| 선 | 상승 | 하락 |
| 중립 | 변화 없음 | 변화 없음 |
| 악 | 하락 | 상승 |
- 변동 수치: 기본 ±8 × 성격 계수 [임시값] → `affinity.delta_post_choice` (D-109)
- 성향 데이터: `data/servants/{id}/profile.json`의 `alignment`. 현재 데이터는 원작 설정 기준 입력값이며 `alignment_verified: false`로 검증 대기 (`content/servants-5th.md` §3)
- 선/중립/악이 아닌 성향(헤라클레스 "광기" 등)은 **중립** [확정] (D-079)
- **현재 구현:** 처치·방면 모두 패배 진영은 탈락한다. 서번트가 이미 쓰러졌고, 방면은 마스터를 살려 보내는 선택이다. 과거의 재조우 문구와의 기획 충돌은 Q-161로 남겨 둔다.
- 처치/방면 시 대사는 마스터별로 작성 (`text.md`)

## 4. 엣지 케이스
| 상황 | 기대 동작 |
|---|---|
| 수치가 0 미만 / 100 초과 | 범위 끝으로 절삭 (현재 구현) |
| 배신 판정 시 영주 0획 | 저지 불가 |
| 명령 거부 발생 | 이동은 인접 무작위 이동으로 대체하며 행동 소비. 조우는 선택 반전. 전투 중 일반 도주는 계속 싸움으로 대체 (D-109, D-134) |

## 5. 예시 (테스트 케이스)
1. 호감도 9 → 적대, 10 → 경계, 49 → 중립, 50 → 호감, 80 → 충성
2. 알트리아(선) 방면 → 호감도 상승. 메데이아(악) 방면 → 하락. 에미야(중립) → 변화 없음
3. 호감도 5(적대), 밤 종료 배신 판정 발동 → 영주 1획으로 저지 → 영주 3 → 2

## 6. 의존성
- 읽는 값: 서번트 성향·초기값·계수(`servants` 데이터)
- 쓰는 값: 판정 보정(`dice.md`), 마력 공급(`mana.md`), 명령 거부·배신(`combat.md`, `day-loop.md`)

## 7. 미정 사항
- 전투 중 행동에 따른 추가 호감도 요인 (현재 미구현)
- 방면의 의미·재조우 여부 (Q-161). 현재 동작은 §3.5
