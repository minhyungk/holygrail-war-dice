# 텍스트 (대사, 타이핑 출력, AI 에필로그)
상태: 서술 선택·VN 구현, 대사 검수·에필로그는 남은 작업 · 관련: skills.md, combat.md, affinity.md · constants 접두: `text.`

## 1. 목적
이 게임의 재미의 중심 (설계 기둥 1). 상황별 텍스트를 데이터로 관리해 규칙 발동 시점에 정확히 골라 출력한다.
**대사 선택·조립 규칙, 이벤트 로그, 자리표시자는 `narrative-engine.md`가 기준**이다 (D-058). 이 문서는 대사 출처, 상황 태그, 출력 규격, 에필로그를 다룬다.

## 2. 입력 / 출력 / 상태
- 입력: 상황 태그, 화자, 대상, 조건
- 출력: 출력할 대사 1개, 이벤트 로그 항목
- 상태: 직전 출력 대사(반복 방지), 이벤트 로그

## 3. 규칙
### 3.1 대사 출처 [확정]
- 일부는 FGO 대사 세트에서 가져오고, 일부는 직접 작성한다.
- 작성 방식: **AI 초안 → 사용자 검수** [확정] (D-060, `narrative-engine.md` §10)
- 문체: 나스 키노코·타입문 문체, 원작 대사 적극 인용 [확정] (D-062). 가이드: `.claude/skills/typemoon-dialogue/SKILL.md`
- **에이전트는 대사 본문을 임의로 창작하지 않는다** (AGENTS.md 규칙 7)

### 3.2 대사 매칭
상세 규칙은 `narrative-engine.md` §6. 요약: 구체적일수록 우선한다.
1. 특정 조합 대사 (화자 + 대상 + 상황). 예: 특정 서번트 vs 서번트
2. 서번트 개인 대사 (화자 + 상황)
3. 상황 태그 범용 대사
- 조건·반복 규칙을 만족하는 후보 중 가장 구체적인 계층(서번트 > 클래스 > 공통)을 먼저 고르고(D-144), 그 안에서 조건 수가 가장 많은 대사를 고른다. 같은 풀에 대안이 있으면 직전 대사 제외 후 가중치 RNG 추첨. `priority` 필드는 쓰지 않는다 (현재 구현, D-104)

### 3.3 자리표시자
목록과 조사 처리, 정보 가림은 `narrative-engine.md` §7 [확정] (D-104).
