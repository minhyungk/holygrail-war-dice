# 스킬, 훅, 효과
상태: 구조·자동 발동 [확정], 전투 훅 4개·효과 4종·스킬 43개 정의 구현 (D-142, 효과·수치 [임시값]), 비전투 훅 [제안] · 관련: combat.md, dice.md, text.md · constants 접두: `skill.`

> **현재 구현 범위 (D-142, D-102 대체):** 전투 스킬은 전투 중 실시간으로 자동 발동한다. 정의는 `data/common/skills.json`, 효과량은 constants `skill.*`, 판단은 `src/engine/skills.ts`, 훅은 `src/engine/hooks.ts`. 스킬 효과는 사용자가 AI에게 맡긴 **[임시값]**이다 (§13). 비전투 스킬은 기존대로 기승(이동)·기척감지(정보 수집)만 개별 적용한다.

## 1. 목적
서번트의 스킬을 **자동 발동하는 반응형 규칙**으로 구현한다 (D-007). 스킬은 텍스트가 나오는 계기이며, 원작과 다른 전개(이변)의 씨앗이다.

## 2. 구조 [확정]
스킬 = `훅 + 조건 + 효과 + 텍스트`
1. 훅이 호출되면 해당 서번트의 스킬 중 그 훅에 붙은 것을 조회한다.
2. 조건이 맞으면 자동 발동 → 효과 적용 → 텍스트 출력.
3. 2층 구조: **범용 스킬**(랭크 연동, 여러 서번트가 공유) + **고유 스킬/보구**(효과 개별 지정).
4. 범용 스킬의 효과 크기는 랭크가 정한다. 랭크별 크기는 `skills` 데이터의 `scaling_rule`.
5. **전투 스킬은 전투 중에만** 발동하고, 비전투 스킬(기승의 이동, 천리안의 시야 등)은 전투 밖에서 적용한다 (D-078). 스킬 기준은 FGO 데이터 (D-078)
6. 훅은 `src/engine/hooks.ts` 한 파일에 enum + 주석으로 정의한다.

## 4. 효과 종류
`roll_mod`, `condition_guard`, `event_negate`, `resource_change`는 구현했다 [임시값] (D-142). 나머지는 [제안].
추가 시 `effect_types` 데이터, 코드 enum, 이 표를 함께 수정한다.
| effect_type | 파라미터 | 설명 |
|---|---|---|
| `roll_mod` | target, amount | 굴림 보정 ±n |
| `condition_guard` | times | 상태 단계 하락 N회 무시 (전투속행 계열) |
| `event_negate` | event_kind | 특정 효과 무효화. 구현: `affinity_penalty`(자기 음수 호감도 보정), `intel`(상대 정보 보정) |
| `event_flip` | event_kind | 결과 뒤집기 (즉사 회피 등) |
| `info_conceal` | target | 진명/정보 은닉 |
| `info_reveal` | target, amount | 정보 공개/획득 |
| `phase_override` | phase_id | 국면 유형 변경/강제 |
| `resource_change` | resource, amount | 마력/영주/운명점 증감. 구현: 마력 (최대 `mana.max`) |

## 6. 실행 규칙
| # | 항목 | 규칙 | 상태 |
|---|---|---|---|
| 1 | 발동 판단 | **조건 충족 시 자동 발동.** 성향 판단 없음 | [확정] D-042 |
| 2 | 실행 순서 | 한 훅에서 a측 → b측, 각자 보유 목록 순서 | [임시값] D-142 |
| 3 | 효과 중첩 | 보정은 모두 합산하고, 대항 판정은 기존 보정 차이 상한 `dice.modifier_gap_cap`을 그대로 적용한다 | [임시값] D-142 |
| 4 | 비용 | 비용·쿨다운 없음. 전투당 횟수는 `uses_per_battle` (불요불굴 1회). 없으면 무제한 | [임시값] D-142 |
| 5 | 텍스트 | 발동 시 `text_id_on_trigger` 출력. 텍스트가 없으면 검증 경고 | [확정] |
| 6 | 발동 기록 | 발동마다 `skill_triggered` 이벤트. 판정 보정은 굴림보다 먼저 기록하고, 그 판정의 parts에 `skill_id`(상대에게 건 것은 `foe:skill_id`)로 남는다. 굴리지 않는 쪽에 닿는 효과는 발동하지 않는다 | [임시값] D-142 |
| 7 | 화면 | 발동한 쪽 카드 위에 스킬 이름표, 판정 카드에 스킬 줄. 버팀·마력 변화만 시스템 문구. 적 스킬 이름은 진명(정보 3단계) 전엔 "스킬"로 가리고, 수치는 정보 2단계부터 | [임시값] D-142 |
| 8 | 대사 | 스킬 발동 대사·나레이션은 아직 없다 (규칙 7). 요청 시 초안 작성 | [TBD] |

## 9. 예시 (테스트 케이스, `src/engine/skills.test.ts`)
1. 대마력 A: 알트리아가 마술전 방어측 → 판정 +2, parts `sk_magic_resistance: 2`. 발동 기록이 굴림 기록보다 먼저
2. 마안 A+: 메두사가 즉사/우연 공격측 → 방어측 알트리아 판정 −2 (`foe:sk_mystic_eyes`)
3. 즉사/우연에서 굴리지 않는 공격측의 카리스마는 발동하지 않는다
4. 단독행동: 에미야(호감도 보정 −2)의 호감도 줄이 사라진다
5. 소와의 소양: 코지로와 싸우는 쪽의 정보 보정이 사라진다
6. 키르케의 가르침: 국면마다 마력 +5
7. 불요불굴 A: 위험의 헤라클레스가 국면에 져도 1회 위험에서 버티고(`phase_resolved.condition_to = danger`), 다음에 지면 쓰러진다
8. 선혈신전: 상대 상태 하락 직후 마력 +10

## 13. 스킬 효과표 [임시값] (D-142)
랭크 효과량 `skill.rank_amount` (문자 기준, +/- 무시): major E·D 0.5 / C 1 / B 1.5 / A 2 / EX 2.5, minor E 0 / D·C 0.5 / B·A 1 / EX 1.5. 고정량 `skill.fixed_amount`.
| 스킬 | 훅 | 조건 | 효과 |
|---|---|---|---|
| 대마력 | 판정 | 마술전 방어측 | 자기 +major |
| 신성 | 판정 | 보구 격돌·일방 보구 | 자기 +minor (E- 메두사는 0) |
| 카리스마 | 판정 | 국면 1 | 자기 +major |
| 심안(가짜) | 판정 | 선제/회피·즉사/우연 | 자기 +major |
| 단독행동 | 판정 | — | 자기 음수 호감도 보정 무효 |
| 기척 차단 | 판정 | 국면 1의 선제/회피 | 자기 +major |
| 진지작성 | 판정 | 진지 보정을 받는 중 | 자기 +major |
| 용의 노심 | 판정 | 정면 격돌·보구 격돌 | 자기 +major |
| 빛나는 길 | 판정 | 자기 상태 위험 | 자기 +major |
| 심안(진짜) | 판정 | 방어측 | 자기 +major |
| 매의 눈 | 판정 | 선제/회피 공격측 | 자기 +major |
| 회로접속 | 판정 | 마술전 | 자기 +major |
| 네 가지의 여울 | 판정 | 정면 격돌 | 자기 +major |
| 화살 회피의 가호 | 판정 | 선제/회피·일방 보구 방어측 | 자기 +major |
| 재정비 | 도주 | 도주하는 쪽 | 자기 +major |
| 마안 | 판정 | 즉사/우연 공격측 | 상대 −major |
| 괴력 | 판정 | 정면 격돌 | 자기 +major |

| 투화 | 판정 | 즉사/우연 | 자기 +major |
| 소와의 소양 | 판정 | — | 상대 정보 보정 무효 |
| 용맹 | 판정 | 정면 격돌·보구 격돌 | 자기 +major |
| 불요불굴 | 상태 변화 | 위험에서 쓰러지려 함 | 위험에서 버팀, 전투당 1회 |
| 기승·도구작성·광화·보구 7종 | 없음 | — | 기승은 이동, 광화는 스탯에 반영, 보구는 보구 스탯으로 판정 |

**밸런스 참고 (강제 전투 규칙 1:1, 상대 6기와 400회씩 붙인 평균 승률. 영주·보구 개입 없음):** 스킬 없음 → 있음. 알트리아 73 → 77%, 에미야 29 → 42%, 쿠 훌린 48 → 43%, 메두사 50 → 44%, 메데이아 35 → 30%, 코지로 27 → 23%, 헤라클레스 84 → 91%. 강자가 더 강해지므로 조정이 필요하면 `skill.*`와 `skills.json`에서 한다.
