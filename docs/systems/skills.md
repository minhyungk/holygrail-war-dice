# 스킬, 훅, 효과
상태: 구조·자동 발동 [확정], 전투 훅 4개·효과 4종·스킬 43개 정의 구현 (D-142, 효과·수치 [임시값]), 비전투 훅 [제안] · 관련: combat.md, dice.md, text.md · constants 접두: `skill.`

> **현재 구현 범위 (D-142, D-102 대체):** 전투 스킬은 전투 중 실시간으로 자동 발동한다. 정의는 `data/common/skills.json`, 효과량은 constants `skill.*`, 판단은 `src/engine/skills.ts`, 훅은 `src/engine/hooks.ts`. 스킬 효과는 사용자가 AI에게 맡긴 **[임시값]**이다 (§13). 비전투 스킬은 기존대로 기승(이동)·기척감지(정보 수집)만 개별 적용한다.

## 1. 목적
서번트의 스킬을 **자동 발동하는 반응형 규칙**으로 구현한다 (D-007). 스킬은 텍스트가 나오는 계기이며, 원작과 다른 전개(이변)의 씨앗이다.

## 2. 구조 [확정]
스킬 = `훅 + 조건 + 효과 + 텍스트`
1. 훅이 호출되면 해당 서번트의 스킬 중 그 훅에 붙은 것을 조회한다.
2. 조건이 맞으면 자동 발동 → 효과 적용 → 텍스트 출력.
3. 2층 구조: **범용 스킬**(랭크 연동, 여러 서번트가 공유) + **고유 스킬/보구**(효과 개별 지정).
4. 범용 스킬의 효과 크기는 랭크가 정한다. 랭크별 크기는 `skills` 데이터의 `scaling_rule`.
5. **전투 스킬은 전투 중에만** 발동하고, 비전투 스킬(기승의 이동, 천리안의 시야 등)은 전투 밖에서 적용한다 (D-078). 스킬 기준은 FGO 데이터 (D-078)
6. 훅은 `src/engine/hooks.ts` 한 파일에 enum + 주석으로 정의한다.

## 4. 효과 종류
`roll_mod`, `condition_guard`, `event_negate`, `resource_change`는 구현했다 [임시값] (D-142). 나머지는 [제안].
추가 시 `effect_types` 데이터, 코드 enum, 이 표를 함께 수정한다.
| effect_type | 파라미터 | 설명 |
|---|---|---|
| `roll_mod` | target, amount | 굴림 보정 ±n |
| `condition_guard` | times | 상태 단계 하락 N회 무시 (전투속행 계열) |
| `event_negate` | event_kind | 특정 효과 무효화. 구현: `affinity_penalty`(자기 음수 호감도 보정), `intel`(상대 정보 보정) |

| `info_conceal` | target | 진명/정보 은닉 |
| `info_reveal` | target, amount | 정보 공개/획득 |
| `phase_override` | phase_id | 국면 유형 변경/강제 |
| `resource_change` | resource, amount | 마력/영주/운명점 증감. 구현: 마력 (최대 `mana.max`) |

## 9. 예시 (테스트 케이스, `src/engine/skills.test.ts`)
1. 대마력 A: 알트리아가 마술전 방어측 → 판정 +2, parts `sk_magic_resistance: 2`. 발동 기록이 굴림 기록보다 먼저
2. 마안 A+: 메두사가 선제/회피 공격측 → 방어측 알트리아 판정 −2 (`foe:sk_mystic_eyes`, D-163)
3. 즉사/우연에서 굴리지 않는 공격측의 판정 보정은 발동하지 않는다: 저주의 팔 하산(공격측) vs 쿠 훌린(둘 다 즉사 수단)에서 하산의 투척/회수(R11, 즉사/우연 +minor)는 발동하지 않는다 (D-163)
4. 단독행동: 에미야(호감도 보정 −1, D-159)의 호감도 줄이 사라진다
5. 소와의 소양: 코지로와 싸우는 쪽의 정보 보정이 사라진다
6. 키르케의 가르침: 국면마다 마력 +5
7. 불요불굴 A: 위험의 헤라클레스가 국면에 져도 1회 위험에서 버티고(`phase_resolved.condition_to = danger`), 다음에 지면 쓰러진다
8. 선혈신전: 상대 상태 하락 직후 마력 +10

## 14. 편입 서번트 스킬 자동 배정 [확정: 방식, 결과 임시값] (D-157)
시작 7기 밖의 서번트 스킬은 `scripts/activate-skills.mjs`가 Atlas 스킬의 버프 종류로 정의를 만든다 (D-143 3층 범용). 같은 계열(랭크를 뺀 이름)은 정의 하나를 공유하고, 기존 계열과 이름이 같으면 기존 정의를 쓴다. 보정량은 랭크 문자로 (`skill.rank_amount`, 마력은 `skill.rank_mana`). 결과 보고서: `data/servants-pool/activation/skill-report.md`.
규칙은 위에서부터 처음 맞는 하나 (적 대상 버프는 R7·R8에만):
| 규칙 | Atlas 효과 | 게임 효과 |
|---|---|---|
| R1 | 거츠 | 위험에서 쓰러질 때 1회 버팀 |
| R2 | 회피·무적 | 선제/회피·즉사/우연 방어측 +major |
| R4 | 보구 위력 업 | 보구 국면 +major |
| R5 | 카드 성능 업 (버스터 → 정면 격돌, 아츠 → 마술전, 퀵 → 선제/회피, 복수 → 셋 다) | 해당 국면 +major |
| R6 | 공격력·특수 공격·크리티컬 위력 업, 무적·회피 관통 | 정면 격돌 +major |
| R3 | NP 획득·충전 (판정 버프가 없을 때만) | 전투 첫 국면 시작에 마력 +`skill.rank_mana` |
| R7 | 적 행동 불능·매료·스턴·스킬/보구 봉인 | 선제/회피 공격측일 때 상대 −major (D-163) |
| R8 | 적 방어·공격·내성 다운 | 상대 −minor |
| R9 | 방어력 업·피해 감소·타깃 집중 | 방어측 +minor |
| R10 | 상태이상·즉사 부여 확률 업 | 즉사/우연 공격측 +major |
| R11 | 크리티컬 확률·스타 | 즉사/우연 +minor |
