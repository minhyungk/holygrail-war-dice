# 스탯
상태: 6스탯 [제안], 랭크 변환 [확정] · 관련: dice.md, phases.md, mana.md · constants 접두: `stats.`

## 1. 목적
판정에 쓰이는 능력치 정의와 랭크 → 수치 변환. 변환된 수치가 그대로 판정 보정이 된다 (D-035).

## 2. 서번트 스탯 [제안: 원작 6스탯]
| 스탯 ID | 이름 | 주 사용처 |
|---|---|---|
| `str` | 근력 | 정면 격돌 |
| `end` | 내구 | 정면 격돌, 일방 보구 방어 |
| `agi` | 민첩 | 선제/회피, 기습, 도주 |

## 3. 규칙
### 3.1 랭크 → 수치 [확정] → `stats.rank_value`
| 랭크 | E | D | C | B | A | EX |
|---|---|---|---|---|---|---|
| 수치 | 3 | 4 | 5 | 6 | 7 | 8 |

### 3.2 수식어 [확정] → `stats.rank_modifier_step` = 0.5
- `+` 하나당 +0.5, `-` 하나당 -0.5
- 예: A+ = 7.5, A++ = 8, B- = 5.5

### 3.3 특수 표기 [확정: 레거시 값 재사용] (D-039)
레거시 `legacy/data/types.ts`의 `statRankToScore` 기준.
| 표기 | 레거시 값 | 해당 서번트 (시작 7기) |
|---|---|---|
| `?` | **7 (A)** | 에미야 보구 |
| `None` | **5 (C)** | 사사키 코지로 보구 |
| `A?` | 7 | 없음 |
| `A+++`, `C+++` | 7, 5 (레거시는 `+++`를 인식하지 못해 수식어 무시) | 없음 |
- `?` = **7(A)** [확정] (D-073)
- `+++` 는 레거시 처리 대신 §3.2 규칙(+1.5)을 쓰는 게 일관적이다 [제안]. 시작 7기에는 해당 없음. 현재 파서는 §3.2의 + 개수 규칙을 적용한다.

## 4. 엣지 케이스
| 상황 | 기대 동작 |
|---|---|
| A++ 와 EX | 수치는 둘 다 8. 기적 구간은 문자 기준이라 A++ → A~B 구간, EX → EX 구간 |

## 5. 예시 (테스트 케이스)
시작 7기 수치는 `docs/content/servants-5th.md` §2.
1. 헤라클레스 근력 A+ → 7.5, 내구 A → 7. 정면 격돌 = 14.5
2. 메데이아 근력 E → 3, 내구 D → 4. 정면 격돌 = 7
3. 에미야 보구 `?` → 7, 코지로 보구 `None` → 5
