# 낮·밤 루프, 맵, 조우, 적 AI
상태: 시간·맵·적 AI·낮 메뉴 [확정] (D-145~D-149), 기습·칸 보너스·AI 추적 등 수치 [임시값] · 관련: combat.md, mana.md, affinity.md, content/map-fuyuki.md · constants 접두: `day.`, `ai.`

## 1. 목적
전투 전의 진행 전체(시간, 행동, 이동, 정보, 조우)와 적 진영의 행동을 정의한다.

## 2. 입력 / 출력 / 상태
- 입력: 플레이어 행동 선택, 적 AI 이동
- 출력: 진영 위치, 획득 정보, 마력·호감도 변동, 조우 발생
- 상태: 일차, 시간대(낮/밤), 남은 행동 수, 각 진영 위치, 진영별 정보 단계, 오늘 마력 공급 여부

## 3. 시간 구조 [확정] (D-048)
| 항목 | 값 |
|---|---|
| 총 일수 | 7일 → `day.days` = 7 |
| 하루 | 아침 마력 공급 요청 → 낮 행동 1회 → 밤 행동 2회 → `day.actions_day` = 1, `day.actions_night` = 2 (D-145) |
| 밤이 끝날 때 | 배신 판정 → 다음 날 낮 |
| 밤에 들어갈 때 | 상태 1단계 회복 (`combat.md` §3.4, D-167: 밤에 다친 상태로 다음 날 낮을 보낸 뒤 회복). 낮에는 상태 회복 없음 (D-169). 적 AI 마력 자연 회복 (`mana.md` §3.1). 플레이어 마력은 회복 없음 (D-111) |
| 7일차 밤이 끝날 때 | 강제 전투 (`combat.md` §7) |

낮 행동 = 플레이어 메뉴 선택(정보 수집 / 교류) → 적 AI 전원 이동. 밤 행동 = 플레이어 이동·머무르기 → 적 AI 전원 이동 → 조우 판정 (D-109, D-145)

## 4. 행동
### 4.1 낮 행동 [확정] (D-145)
낮에는 이동하지 않는다. 행동 1회로 메뉴에서 하나를 고른다. 판정은 자동이며 주사위·수치를 보여 주지 않고, 결과만 서술과 한 줄 요약으로 보인다. 운명점 재굴림은 없다.
| 메뉴 | 판정 | 결과 | 훅 |
|---|---|---|---|
| 정보 수집 | 2d6 + 기척감지 랭크 수치 + 호감도 보정 + 칸 보너스 ≥ 목표 단계 DC | 대상 진영 정보 단계 +1 (§4.3) | `hk_day_intel` |
| 교류 | 2d6 + 호감도 보정 + 칸 보너스 ≥ `day.bond_dc` | 호감도 증감 (§13) | `hk_day_bond` |
- **칸 보너스** [임시값] → `day.role_bonus`: 밤을 마친(=낮을 보내는) 칸의 역할(`tiles.json` `role`)이 판정에 더해진다. 화면에는 수치 없이 "성공률 ↑"로만 표시한다 (D-156)
  | 칸 역할 | 보너스 |
  |---|---|
  | 정보 (`intel`) | 정보 수집 +2 |
  | 교류 (`bond`) | 교류 +2 |
  | 영맥 (`leyline`) | 아침 마력 공급 +2 (`mana.md` §3.3). 그날 아침 공급에 적용 |
- 마력 공급은 아침 요청으로만 벌어지고 행동을 쓰지 않는다 (D-129). 직접 굴린다.
- 진지 작성은 폐기 (D-146).
- 표의 훅 연결은 D-102에 따라 아직 미구현이다.

### 4.2 밤 행동
- **조우와 전투는 밤에만** 일어난다 [확정] (D-077)
- 밤 행동 = **이동** [확정] (D-106, D-112), **2회** (D-145). 이동에서 자기 칸을 고르면 머문다. 매 행동 뒤 적 AI 이동 → 같은 타일이면 조우
- 밤을 어디서 마치느냐가 다음 날 칸 보너스를 정한다 (§4.1)

### 4.3 정보 [확정] (D-049, D-147, D-158)
적 진영마다 따로 쌓는다.
| 단계 | 공개 내용 (해금 전은 가림, D-086) | 판정 보정 | 얻는 법 |
|---|---|---|---|
| 0 | 없음 | 0 | |
| 1 | **얼굴**: 얼굴·일러스트, 클래스, 스테이터스 | 0 | **조우·전투하면 자동** |
| 2 | **진명** (이름, 보구명, 스킬 이름) | +0.5 | 정보 수집, 결판 없는 전투, 상대 보구 개방 |
| 3 | **약점**: 약점 문구를 읽어 준다 + **약점 공략 해금** (`combat.md` §4.1) | +1 | 정보 수집, 결판 없는 전투 |
- 보정은 해당 진영과의 전투 판정에 더한다 → `day.intel_mod` = [0, 0, 0.5, 1] [확정] (D-159)
- **자동 공개:** 플레이어가 조우하거나 싸운 적이 0단계면 1단계가 된다 (`intel_gained` cause `encounter`). 조우 후 도주해도 적용. 조우 없이 시작하는 강제 전투도 개시 때 적용
- **결판 없는 전투의 보상:** 플레이어 전투가 무승부이거나 적이 도주(영주 퇴각·일반 도주 성공)로 끝나면 그 적 정보 +1단계 (cause `battle`). 플레이어가 도주한 경우는 없음
- **보구 개방 시 즉시 2단계(진명) 공개** [확정] (D-067, D-137, D-158). 플레이어와 싸우는 적이 개방하면 `np_opened` 직후 `intel_gained`를 기록하고, **그 국면부터 정보 보정**을 적용한다. 이미 2단계 이상이면 아무 일도 없다. 적끼리의 전투에서 연 보구는 플레이어에게 공개하지 않는다 (현재 구현).
- **약점 문구** (D-158): 3단계가 되면 약점 문구를 나레이션으로 읽어 준다. 범용은 Atlas '캐릭터 상세'(`profile.lore.detail`), 개별 오버라이드는 `profile.lore.weakness` (D-143)
- 정보 수집 판정 (DC [임시값] D-138·D-141): 2d6 + 기척감지 랭크 수치(없으면 0) + 호감도 보정 + 칸 보너스 ≥ 목표 단계 DC(1단계 4 / 2단계 7 / 3단계 10) → `day.intel_dc`
- 정보 수집 대상 [임시값]: 살아 있고 약점(3단계)을 모르는 적 중 **이미 만난(1단계 이상)** 진영을 우선하고, 그중 단계가 가장 낮은 진영에서 무작위 1. 만난 적이 없으면 0단계 진영에서 무작위

## 6. 조우 [확정]
| 항목 | 규칙 | 상태 |
|---|---|---|
| 발생 조건 | 같은 타일 | [확정] |
| 3진영 이상 같은 타일 | 무작위 2진영만 전투, 나머지는 아무것도 안 함 (D-052) | [확정] |
| 기습 판정 | 민첩 대항, 차이 3 이상이면 기습. 국면 1 공격측 및 +2 (§13). 기척감지·은신 훅 미연결 | [임시값] D-109 |

## 7. 적 AI [확정] (D-051, D-045)
1. 마스터 × 서번트 조합은 게임 시작 시 랜덤 (D-045)
2. **매 행동마다 무작위 이동**한다. 머무르기도 인접 칸 이동과 같은 확률의 선택지 하나 [확정] (D-082)
2-1. **추적** [임시값] (D-149): `ai.hunt_from_day`일차부터는 `ai.hunt_chance` 확률로 가장 가까운(상하좌우 거리) 다른 생존 진영 쪽으로 한 칸 다가간다. 거리가 같으면 무작위. 같은 칸이면 머문다
3. 같은 타일에서 만나면 3국면 자동 전투 (`combat.md` §8)
4. 위험 진입 시 마스터 성향으로 계속 싸울지 정한다. 퇴각은 영주 우선, 없으면 일반 도주 (D-134). **영주 퇴각은 진영당 판 1회** (`ai.seal_retreat_max`, D-149), 이후 퇴각은 일반 도주
5. **마력 공급을 하지 않는다.** 마력은 자연 회복만
6. 정보 수집·교류·제작 등 다른 행동은 하지 않는다 (현재 구현)
- 레거시 `ai.ts`의 의도 가중치(`INTENT_WEIGHTS`), `FORCED_HUNT_DAY`, 승률 임계값은 무작위 이동으로 대체되어 쓰지 않는다 (D-028 대체)

## 8. 플레이어 패배 후 (D-043)
플레이어가 패배하면 남은 일수를 적 AI 규칙만으로 빨리감기해 최종 우승자를 보여준다. 강제 전투 포함.

## 10. 예시 (테스트 케이스)
1. 시야: 플레이어 (3,3). 적 A (3,4), 적 B (3,5) → A만 보인다. 천리안 3칸이면 둘 다 보인다
2. 기승 A+ 메두사: 한 행동에 최대 3칸 이동 ((3,3) → (3,4) → (3,5) → (2,5) 등)
3. 정보: 적 진영 정보 단계 2(진명) → 그 진영과의 모든 국면 판정 +0.5. 3단계(약점) → +1 (D-159)
4. 3진영 같은 타일 (플레이어, 적 A, 적 B): 추첨 결과 A vs B → 자동 전투, 플레이어 대기
5. 칸 보너스: 교류 칸에서 밤을 마침 → 다음 날 교류 판정 2d6 + 호감도 보정 + 2. 자연값 5, 중립이면 7 ≥ DC 7 성공
6. 결판 없는 전투: 1단계(클래스)인 적과 3국면 무승부 → 그 적 2단계

## 13. AI 임시값 (D-109)
사용자가 "알아서 잘"로 맡긴 값. 튜닝 값은 `data/constants.json`에 있다. D-138로 재조정한 교류 DC를 포함한 아래 튜닝 값은 `status: 임시값`이다. 플레이해 보고 조정한다.
| 항목 | 값 | constants |
|---|---|---|
| 시작 위치 | 모든 진영 서로 다른 타일, 중앙 제외, 시드 RNG | — |
| 한 행동의 순서 | 플레이어 행동 → 적 AI 전원 이동 → (밤) 조우 판정 | — |
| 교류 | 2d6 + 호감도 보정 ≥ **7** (D-138, 임시값) → 호감도 +5, 실패 -3 (× 성격 계수) | `day.bond_dc`, `affinity.delta_bond` |
| 마력 공급 호감도 | 대성공 +6 / 성공 +3 / 보통 0 / 실패 -2 / 대실패 -5 (× 계수) | `affinity.delta_supply` |
| 처치 / 방면 | ±8 (선: 방면 +, 처치 −. 악: 반대. 중립 0) | `affinity.delta_post_choice` |

| 호감도 판정 보정 적용 범위 | 플레이어 서번트의 모든 판정 (전투·낮 행동·도주·마력 공급) | `affinity.roll_mod` |
| 칸 보너스 | 정보 칸 → 정보 수집 +2, 교류 칸 → 교류 +2, 영맥 칸 → 아침 마력 공급 +2 (D-145) | `day.role_bonus` |
| 기습 | 조우 시 양측 2d6 + 민첩 대항(자동), 3 이상 차이로 이긴 쪽이 기습 → 국면 1 공격측 + 국면 1 판정 +2 | `day.ambush_margin`, `day.ambush_bonus` |

| 적 AI 영주 퇴각 | 진영당 판 `ai.seal_retreat_max`회 (D-149) | `ai.seal_retreat_max` |
| 수락하지 않은 쪽 | 도주 시도: 민첩 대항, 동점은 도주 성공 (D-100) | — |
| 정보 수집 대상 | 이미 만난 적 우선, 그중 정보 단계가 가장 낮은 진영들에서 무작위 1 (D-147) | — |

### 2d6 전환 (D-138)
정보 DC·교류 DC·기습 차이는 이번 요청으로 재조정한 [임시값]이다. 나머지 행동 효과량은 기존 값을 쓴다.
