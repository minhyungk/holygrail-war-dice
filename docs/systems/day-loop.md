# 낮·밤 루프, 맵, 조우, 적 AI
상태: 시간·맵·적 AI [확정], 행동별 DC·기습 [TBD] · 관련: combat.md, mana.md, affinity.md, content/map-fuyuki.md · constants 접두: `day.`, `ai.`

## 1. 목적
전투 전의 진행 전체(시간, 행동, 이동, 정보, 조우)와 적 진영의 행동을 정의한다.

## 2. 입력 / 출력 / 상태
- 입력: 플레이어 행동 선택, 적 AI 이동
- 출력: 진영 위치, 획득 정보, 마력·호감도 변동, 조우 발생
- 상태: 일차, 시간대(낮/밤), 남은 행동 수, 각 진영 위치, 진영별 정보 단계, 오늘 마력 공급 여부

## 3. 시간 구조 [확정] (D-048)
| 항목 | 값 |
|---|---|
| 총 일수 | 7일 → `day.days` = 7 |
| 하루 | 낮 행동 3회 → 밤 행동 3회 → `day.actions_day` = 3, `day.actions_night` = 3 |
| 밤이 끝날 때 | 상태 1단계 회복 (`combat.md` §3.4) → 다음 날 낮 |
| 밤에 들어갈 때 | 적 AI 마력 자연 회복 (`mana.md` §3.1). 플레이어는 회복 없음 (D-111) |
| 7일차 밤이 끝날 때 | 강제 전투 (`combat.md` §7) |

한 행동 = 플레이어 행동 1회 + 모든 적 AI 이동 1회 + 조우 판정 [제안]

## 4. 행동
### 4.1 낮 행동
> **D-128로 바뀌었다.** 낮 행동 메뉴는 없고 이동뿐이다. 낮에 도착하거나 머문 칸의 역할(`tiles.json` `role`)이 자동으로 벌어진다: 영맥 → 진지 작성 제안, 정보 → 정보 수집, 교류 → 교류. 마력 공급은 아침 요청으로만 (D-129). 아래 표는 각 판정의 내용으로 유효하다.

| 행동 | 결과 | 제한 | 훅 |
|---|---|---|---|
| 정보 수집 | 다른 진영 정보 단계 +1 (§4.3) | | `hk_day_intel` |
| 제작 / 진지 작성 | 진지 작성: 그 타일에서 스탯 버프 [확정] D-082 | 수치·지속 [TBD] | `hk_day_craft` |
| 마력 공급 | `mana.md` §3.3 | **하루 1회** [확정] | `hk_day_mana_supply` |
| 서번트 교류 | 호감도 증감 [확정] D-082, 텍스트 | | `hk_day_bond` |
| 이동 | 타일 이동 (§5) | | `hk_day_move` |
- 모든 행동은 다이스 판정을 거친다 [확정]. 행동별 굴리는 스탯, DC, 성공/실패 보상: [TBD] (DC 제안값 `dice.md` §3.2)

### 4.2 밤 행동
- **조우와 전투는 밤에만** 일어난다 [확정] (D-077)
- 밤 행동 = **이동** [확정] (D-106, D-112). 이동에서 자기 칸을 고르면 머문다. 매 행동 뒤 적 AI 이동 → 같은 타일이면 조우

### 4.3 정보 [확정] (D-049)
적 진영마다 따로 쌓는다.
| 단계 | 공개 내용 (해금 전 스탯·프로필은 가림, D-086) | 판정 보정 |
|---|---|---|
| 0 | 없음 | 0 |
| 1 | 클래스 | +1 |
| 2 | 스테이터스 | +2 |
| 3 | 진명 | +3 |
- 보정은 해당 진영과의 전투 판정에 더한다 → `day.intel_mod`
- **보구 개방 시 즉시 3단계(진명) 공개** [확정] (D-067). 적끼리의 전투에서 연 보구는 플레이어가 보지 못했으므로 공개되지 않는다 [제안]
- 단계별 획득 확률 [확정] (D-107): 2d10 + 기척감지 랭크 수치(없으면 0) + 호감도 보정 ≥ 목표 단계 DC(1단계 12 / 2단계 16 / 3단계 20) → `day.intel_dc`

## 5. 맵과 이동 [확정] (D-048, D-050)
| 항목 | 규칙 | 상태 |
|---|---|---|
| 맵 | 5×5, `content/map-fuyuki.md` | [확정] |
| 중앙 타일 | (3,3) | [제안] |
| 기본 이동 | 1칸 → `day.move_base` = 1 | [확정] |
| 기승 | A 이상 3칸, B~C 2칸, D 이하 1칸 → `day.riding_move` | [확정] D-073 |
| 기본 시야 | **인접 칸까지** 보인다 (거리 1). 두 칸 떨어지면 안 보인다. **낮에는 적 위치가 보이지 않는다** (D-110) | [확정] |
| 천리안류 | A 이상 3칸, B~C 2칸 → `day.clairvoyance_range` | [확정] D-073 |
| 은신 | 은신 스킬이 있으면 안 보인다 | [확정] |
| 인접 기준 | 상하좌우 4방향 | [확정] D-073 |

예: 한 줄로 ㅁ ㄴ ㅇ ㄹ 이 있고 내가 ㄴ에 있으면 ㅁ, ㅇ은 보이고 ㄹ은 안 보인다.

## 6. 조우 [확정]
| 항목 | 규칙 | 상태 |
|---|---|---|
| 발생 조건 | 같은 타일 | [확정] |
| 3진영 이상 같은 타일 | 무작위 2진영만 전투, 나머지는 아무것도 안 함 (D-052) | [확정] |
| 기습 판정 | 기척감지, 은신, 민첩을 섞은 다이스 판정. 식과 보정값 [TBD] | 개념 [확정] |
| 조우 후 선택 (플레이어) | 전투 개시 / 도주 | [확정] |
| 도주 판정 | 도주를 골라도 상대가 전투를 원하면 양측 민첩 대항. 이기면 도주, 지면 전투 돌입 | [확정] D-085 |
| 적 AI의 조우 후 선택 | 마스터 성향으로 수락 여부 (D-088, `content/masters.md` §2, 수치 [임시값] D-109) | [확정] |

## 7. 적 AI [확정] (D-051, D-045)
1. 마스터 × 서번트 조합은 게임 시작 시 랜덤 (D-045)
2. **매 행동마다 무작위 이동**한다. 머무르기도 인접 칸 이동과 같은 확률의 선택지 하나 [확정] (D-082)
3. 같은 타일에서 만나면 3국면 자동 전투 (`combat.md` §8)
4. `위험`에서 지면 남은 영주로 도주한다
5. **마력 공급을 하지 않는다.** 마력은 자연 회복만
6. 정보 수집·교류·제작 등 다른 행동은 하지 않는다 [제안]
- 레거시 `ai.ts`의 의도 가중치(`INTENT_WEIGHTS`), `FORCED_HUNT_DAY`, 승률 임계값은 무작위 이동으로 대체되어 쓰지 않는다 (D-028 대체)

## 8. 플레이어 패배 후 (D-043)
플레이어가 패배하면 남은 일수를 적 AI 규칙만으로 빨리감기해 최종 우승자를 보여준다. 강제 전투 포함.

## 9. 엣지 케이스
| 상황 | 기대 동작 |
|---|---|
| 3진영 이상 같은 타일, 플레이어가 뽑히지 않음 | 플레이어는 아무것도 안 함 |
| 맵 가장자리에서 무작위 이동 | 갈 수 있는 인접 칸 중에서만 추첨 |
| 은신 진영끼리 같은 타일 | [TBD] |
| 마지막 적을 7일차 전에 격파 | 즉시 우승 (S6) |

## 10. 예시 (테스트 케이스)
1. 시야: 플레이어 (3,3). 적 A (3,4), 적 B (3,5) → A만 보인다. 천리안 3칸이면 둘 다 보인다
2. 기승 A+ 메두사: 한 행동에 최대 3칸 이동 ((3,3) → (3,4) → (3,5) → (2,5) 등)
3. 정보: 적 진영 정보 단계 2(스테이터스) → 그 진영과의 모든 국면 판정 +2
4. 3진영 같은 타일 (플레이어, 적 A, 적 B): 추첨 결과 A vs B → 자동 전투, 플레이어 대기

## 11. 의존성
- 읽는 값: 스탯·스킬 랭크(`content/servants-5th.md`), 지형(`content/map-fuyuki.md`)
- 쓰는 값: 위치, 정보 단계, 마력(`mana.md`), 호감도(`affinity.md`), 조우 → `combat.md`

## 12. 미정 사항 (이전 목록, §13 임시값으로 일부 해소)
- 밤 행동의 종류, 조우가 낮에도 일어나는지
- 낮 행동별 스탯·DC·보상, 제작 결과물
- 정보 단계 획득 DC
- 기승·천리안 랭크별 칸 수 확정 (§5 제안)
- 기습 판정식과 보정값, 효과 범위
- 적 AI가 머무를 확률, 조우 시 선택
- 은신 진영끼리 같은 타일

## 13. AI 임시값 (D-109)
사용자가 "알아서 잘"로 맡긴 값. 전부 `data/constants.json`에 `status: 임시값`으로 있다. 플레이해 보고 조정한다.
| 항목 | 값 | constants |
|---|---|---|
| 시작 위치 | 모든 진영 서로 다른 타일, 중앙 제외, 시드 RNG | — |
| 한 행동의 순서 | 플레이어 행동 → 적 AI 전원 이동 → (밤) 조우 판정 | — |
| 교류 | 2d10 + 호감도 보정 ≥ **10** (D-132, 확정) → 호감도 +5, 실패 -3 (× 성격 계수) | `day.bond_dc`, `affinity.delta_bond` |
| 마력 공급 호감도 | 대성공 +6 / 성공 +3 / 보통 0 / 실패 -2 / 대실패 -5 (× 계수) | `affinity.delta_supply` |
| 처치 / 방면 | ±8 (선: 방면 +, 처치 −. 악: 반대. 중립 0) | `affinity.delta_post_choice` |
| 성격 계수 | 상승 = 레거시 GAIN_MULTIPLIER, 하락 = PENALTY_MULTIPLIER | `affinity.gain_mult`, `affinity.penalty_mult` |
| 호감도 판정 보정 적용 범위 | 플레이어 서번트의 모든 판정 (전투·낮 행동·도주·마력 공급) | `affinity.roll_mod` |
| 진지 작성 | 2d10 + 마력 스탯 ≥ 16 → 현재 타일이 진지. 그 타일 전투에서 플레이어 판정 +2, 게임 끝까지. 진지는 하나 (새로 지으면 옮김) | `day.craft_dc`, `day.camp_bonus` |
| 기습 | 조우 시 양측 2d10 + 민첩 대항(자동), 5 이상 차이로 이긴 쪽이 기습 → 국면 1 공격측 + 국면 1 판정 +2 | `day.ambush_margin`, `day.ambush_bonus` |
| 적 마스터 전투 수락 | 호전 100% / 오만 80% / 신중 40% / 교활: 예상 승률(6스탯 합 Elo, D=10) 50% 이상이면 수락, 아니면 20% | `ai.accept`, `ai.cunning_win_rate`, `ai.elo_d` |
| 수락하지 않은 쪽 | 도주 시도: 민첩 대항, 동점은 도주 성공 (D-100) | — |
| 정보 수집 대상 | 살아 있는 적 중 정보 단계가 가장 낮은 진영들에서 무작위 1 | — |
| 명령 거부 처리 | 이동 거부 → 인접 무작위 이동(D-083). 조우 전투 개시 거부 → 도주로, 도주 거부 → 전투로. 전투 중 일반 도주 거부 → 쓰러짐(패배). 영주 명령은 거부 불가 | `affinity.refusal_chance` |
| 방면 | 패배한 적 마스터는 전쟁에서 빠진다 (서번트가 이미 소멸) | — |
| 적 AI 이동 | 1칸 (기승 칸 수는 플레이어만) | — |
| 영주 버프 | 전투당 1회 (D-101) | `combat.seal_buff` |
