# 전투
상태: 전투·도주·개입 [확정] (D-100, D-127, D-134~137), 스킬 전투 중 자동 발동 (D-142, 효과 [임시값]) · 관련: phases.md, dice.md, skills.md, stats.md, mana.md · constants 접두: `combat.`

## 1. 목적
서번트끼리의 전투를 **자동 진행**으로 보여주고, 핵심 순간에만 유저에게 선택권을 준다. 마스터는 실시간 지시를 하지 않는다 (D-002).

## 2. 입력 / 출력 / 상태
- 입력: 양측 서번트/마스터, 전투 타일 지형, 기습 여부, 양측 마력·영주·운명점
- 출력: 결과(승/패/무승부/도주), 양측 상태 변화, 이벤트 로그
- 상태: 양측 상태(만전/부상/위험), 진행한 국면 수, 마력, 영주, 발동한 스킬

## 3. 규칙
### 3.1 마스터의 행동 [확정]
전투 중 마스터가 하는 행동은 **개입 지점의 선택**뿐이다. 개시·도주 선택은 조우 화면(`day-loop.md` §6).

### 3.2 진행 [확정]
1. 한 전투는 **국면 3개**로 이루어진다 (D-030) → `combat.phase_count` = 3
2. 국면마다: 국면 시작 스킬 → 보구·영주 지시 → 국면 유형 결정(`phases.md`) → 판정 스킬 → 대항 판정 → 상태 하락(상태 변화 스킬) → 텍스트 출력 (스킬은 `skills.md` §13, D-142)
3. 연출 비트와 국면의 대응 [제안]:
   | 비트 | 내용 |
   |---|---|
   | 조우 | 기습 판정, 전투 개시 텍스트 (국면 아님) |
   | 탐색전 | 국면 1 |
   | 격돌 | 국면 2 |
   | 전환점 | 국면 3 |
   | 결말 | 결과 텍스트 (국면 아님) |

### 3.3 국면 판정 [확정]
1. 판정값 = 2d6 + 국면 스탯 수치(2개면 합산) + 스킬·호감도·정보·영주·기적 보정 (`dice.md` §3.3)
2. 판정값이 높은 쪽이 그 국면의 승자
3. 동점이면 그 국면을 스킵하고 다음 국면으로 진행 (D-017). 스킵한 국면도 3개에 포함된다.

### 3.4 상태
1. 체력은 **3단계**: 만전 → 부상 → 위험 (D-014)
2. 국면에서 지면 1단계 떨어진다. **차이(margin)가 크면 2단계** 떨어진다 [확정] (D-031)
   - "큰 차이" 기준: **이긴 쪽 판정값이 진 쪽 판정값의 2배 이상** [확정] (D-092) → `combat.big_loss_ratio` = 2
   - 과거 2d10의 2단계 하락 비율은 2d6에 적용하지 않는다. 단독 판정 국면(`ph_fate`)에는 적용하지 않는다 (`phases.md` §3.5)
3. **`위험`에 들어서는 순간 정한다** [확정] (D-134, D-032·D-093 대체)
   - **계속 싸운다:** 이후 `위험`에서 국면을 지면 **쓰러진다** (도주 기회 없음)
   - **영주로 퇴각:** 영주 1획 소모, 확정 성공. 영주가 0획이면 선택지에 없다. 거부할 수 없다
   - **일반 도주:** 민첩 대항. 성공하면 이탈, 동점도 성공 (D-100), **실패하면 전쟁 패배**. 명령 거부(D-083)로 거부당하면 계속 싸운다
   - 2단계 하락으로 `위험`을 건너뛰면 `위험`에서 멈추고 묻는다
   - 적 AI는 마스터 성향으로 정한다 (`ai.retreat_chance` [임시값]). 퇴각하면 영주, 영주가 없으면 일반 도주
   - 강제 전투에서는 묻지 않는다 (§7-4)
4. 전투속행 계열 스킬(`condition_guard`, 불요불굴)이 있으면 `위험`에서 쓰러질 때 전투당 1회 버틴다 [확정: 설계]. 구현됨 (D-142): 상태는 위험 그대로, 위험 진입 선택은 다시 묻지 않는다
5. 상태는 전투 중 유지된다 (D-019)
6. **밤이 지나면 1단계 회복**한다 [확정] (D-034) → `combat.night_recovery` = 1
   - 적용 시점: 밤 행동 3회와 배신 판정 뒤. 마지막 밤도 회복한 뒤 강제 전투에 들어간다 (현재 구현)

### 3.5 종료 조건 [확정] (D-016, D-033)
| 결과 | 조건 |
|---|---|
| 승/패 | 한쪽 서번트 사망 |
| 도주 | §3.4-3의 영주 도주 / 일반 도주 |
| 무승부 | **국면 3개를 모두 소진했는데 양측 생존** |
- 전투 중 도주 수단은 §3.4-3의 두 가지뿐 [확정] (D-074)

| 영주 명령 | 매 국면 시작 시, 영주 1획 이상, 보구 미사용 | 영주 보구 즉시 발동 / 사용 안 함. 영주 버프는 폐지 (D-142) | [확정] D-101, D-142 |

## 6. 스킬 발동 [확정] (D-042)
스킬은 해당 훅에서 조건이 맞으면 **자동 발동**한다. 성향 판단은 없다. 상세는 `skills.md`.

## 7. 강제 전투 [확정] (D-025, D-027, D-044)
1. 7일차 밤이 끝나면 남은 진영을 모두 중앙 타일로 소환한다.
2. 1:1 토너먼트. 대진은 **라운드마다** 시드 RNG로 추첨, 진영 수가 홀수면 추첨으로 1진영 부전승 [확정] (D-103).
3. **대진 사이 회복 없음.** 상태를 그대로 가지고 다음 대진에 나간다.
4. **도주 없음.** 영주 도주 선택지가 나오지 않는다 → `위험`에서 지면 사망.
5. **국면이 무한히 이어진다** [확정] (D-075). 3국면 제한 없이 한쪽이 쓰러질 때까지 싸우므로 무승부가 없다
6. 플레이어가 없는 대진은 §8 자동 전투로 처리한다.

## 8. 적끼리의 전투 [확정] (D-051)
1. 플레이어 전투와 **같은 3국면 규칙**을 쓰고, 모든 굴림을 자동으로 처리한다.
1-1. 조우 시 전투 수락 여부는 마스터 성향이 정한다 (D-088, `content/masters.md` §2)
2. 화면 연출 없이 결과만 이벤트 로그에 남긴다. 플레이어에게는 "누군가 탈락했다"처럼 알린다 [확정] (D-085, 소문 나레이션 `narrative-engine.md` §8.7)
3. `위험`에 들어설 때 마스터 성향으로 계속 싸울지 정한다 (D-134). 퇴각이면 영주를 우선 쓰고, 영주가 없으면 일반 도주. 계속 싸운 뒤 위험에서 다시 지면 사망한다.
4. 적 AI의 다른 영주 용도(보구 즉시 발동): 쓰지 않음 [확정] (D-094)
5. 적 AI는 보구를 낮은 확률로만 먼저 열고(`ai.np_open_chance`), **상대가 열면 따라서 연다** [확정] (D-136). 보구는 전투당 1회 (D-135)
6. 적이 적을 이겼을 때 처치/방면: 항상 처치 [확정] (D-094)

## 9. 전투 예상 승률 (D-139, D-140)
- 조우 선택 전, 전투 개시, 국면 시작, 국면 지시와 위험 진입에서 현재 상태 기준으로 갱신한다. 굴림을 공개하는 동안에는 굴리기 전 예측을 유지하며 미래 결과를 미리 읽지 않는다.
- 실제 전투 엔진을 2048회 실행한 추정치 [임시값] (`combat.forecast_samples`). 시드는 139 [임시값] (`combat.forecast_seed`), 실제 판정 RNG와 분리한다.
- 플레이어는 추가 영주·보구·재굴림 없이 계속 싸운다. 이미 사용한 보구·정보 공개·스킬 횟수, 상태, 남은 국면, 기습을 반영한다. 스킬은 실제 전투와 같이 발동한다. 적은 기존 AI 보구·퇴각 정책을 따른다.
- **승/패만 표시한다** [확정] (D-140). 무승부·퇴각(도주 성공)으로 끝난 시행은 세지 않고, 승부가 난 시행 중 승리 비율을 승률, 나머지를 패율로 한다 (합 100%). 일반 전투는 남은 3국면, 강제 전투는 결판까지 계산한다. 적의 일반 도주 실패도 승리에 포함한다.
- 남은 국면으로는 어느 쪽도 쓰러질 수 없어 승부가 난 시행이 0건이면 승/패를 `–`로 표시한다.
- 정수 퍼센트로 표시하고 0건/전부 성공도 확률 0/100으로 단정하지 않는다 (`<1%`, `>99%`). 조우는 선택지 위, 전투 화면은 국면 이름 아래 한 줄 막대로 표시한다 (D-140). 기준·오차 설명 문구는 표시하지 않는다 (D-141).
- 정보 단계에 관계없이 집계 승률은 공개한다. 적의 개별 스탯·진명은 기존 정보 가림을 따른다.

## 10. 엣지 케이스
| 상황 | 기대 동작 |
|---|---|
| 양측 동시에 `위험` | 전투 계속 |
| 국면 판정 동점 | 그 국면 스킵. 3국면 모두 동점이면 무승부 |
| 영주 0획으로 위험 진입 | 계속 싸운다 / 일반 도주. 위험에서 다시 패배하면 영주 유무와 관계없이 사망 |
| 개입 지점에서 자원 부족 | 해당 선택지 비활성 + 이유 텍스트 |
| 강제 전투에서 `위험` 패배 | 도주 선택지 없음 → 사망 |

## 11. 예시 (테스트 케이스, 큰 차이 기준 판정값 2배, 스킬 미반영)
모든 예시는 마력 80 미만, 정보·호감도·진지 보정과 재굴림, **스킬이 없음**을 가정한다 (스킬 예시는 `skills.md` §9). 위험에서는 양측 계속 싸운다. D-138의 2d6 눈과 기적 +3을 적용한다.
1. **강자 우세, 무승부:** 헤라클레스 vs 메데이아(플레이어), 개활지
   - 정면: 14.5 + 7 = 21.5 / 7 + 8 = 15 → 메데이아 만전 → 부상
   - 선제: 7 + 4 = 11 / 5 + 9 = 14 → 헤라클레스 만전 → 부상
   - 정면: 14.5 + 6 = 20.5 / 7 + 5 = 12 → 메데이아 부상 → 위험
   - 양측 생존, 3국면 소진 → 무승부
2. **약자 승 (기적):** 코지로(플레이어) vs 헤라클레스(영주 0), 시가지
   - 선제: 7.5 + 9 = 16.5 / 7 + 6 = 13 → 헤라클레스 부상
   - 정면: 코지로 8 + 12 + 기적 3 = 23 / 헤라클레스 14.5 + 7 = 21.5 → 헤라클레스 위험
   - 선제: 7.5 + 8 = 15.5 / 7 + 6 = 13 → 헤라클레스 사망, 코지로 승
3. **무승부:** 알트리아 vs 쿠 훌린, 수변
   - 정면: 12 + 7 = 19 / 11 + 8 = 19 → 동점, 스킵
   - 선제: 6 + 9 = 15 / 7 + 6 = 13 → 쿠 훌린 부상
   - 정면: 12 + 4 = 16 / 11 + 7 = 18 → 알트리아 부상
   - 양측 생존 → 무승부. 밤 종료 후 양측 만전 회복
4. **강제 전투:** 3번 이후에도 계속된다.
   - 국면 4 선제: 알트리아 6 + 10 = 16 / 쿠 훌린 7 + 3 = 10 → 쿠 훌린 위험
   - 국면 5 정면: 12 + 8 = 20 / 11 + 5 = 16 → 쿠 훌린 사망, 알트리아 승
5. **2단계 하락:** 헤라클레스 정면 14.5 + 10 = 24.5 / 메데이아 7 + 4 = 11 → 24.5 ≥ 11 × 2 → 만전에서 위험
6. **위험 진입:** 부상인 메데이아(플레이어, 영주 3)가 정면에서 21.5 / 15로 패배 → 위험에서 선택
   - 영주 퇴각 → 3 → 2, 전투 결과 도주
   - 일반 도주: 메데이아 민첩 5 + 10 = 15 / 헤라클레스 7 + 6 = 13 → 성공
   - 실패 사례: 메데이아 5 + 6 = 11 / 헤라클레스 7 + 12 + 기적 3 = 22 → 전쟁 패배
   - 계속 싸우면 위험에서 다음 패배 시 사망
   - 적 AI는 성향별 퇴각 확률을 적용한다.
