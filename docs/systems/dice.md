# 주사위와 판정
상태: 2d6·판정 규칙 [확정], DC·상한·기적 튜닝 [임시값] (D-138) · 관련: stats.md, phases.md, combat.md · constants 접두: `dice.`

## 1. 목적
모든 확률 판정을 하나의 규칙으로 통일한다. 이변(약자의 승리)이 가능하되 격차가 무의미하지 않게 한다.

## 2. 입력 / 출력 / 상태
- 입력: 판정 종류, 굴리는 쪽 스탯/보정 목록, (대항이면) 상대 스탯/보정 목록
- 출력: 자연값, 보정 후 값, 성공/실패(또는 승/패/동점), 차이(margin), 기적 여부
- 상태: 시드 RNG 상태, 운명점 잔량

## 3. 규칙
### 3.1 판정 [확정]
1. 판정값 = **2d6 자연값(2~12) + 보정치 합** (D-138) → `dice.die_count` = 2, `dice.die_size` = 6
2. 대항 판정: 양쪽이 굴려 판정값이 큰 쪽이 이긴다. 동점은 무승부.
   - 전투 국면의 동점은 국면 스킵 (`combat.md` §3.3, D-017)
   - 차이(margin) = 이긴 쪽 판정값 − 진 쪽 판정값. 국면의 상태 하락량에 쓰인다 (`combat.md` §3.4)
3. 단독 판정: 판정값 ≥ 난이도(DC)이면 성공.

### 3.2 DC [임시값] (D-138) → `dice.dc`
스탯 수치는 유지한다. 아래 성공률은 기적을 제외한 36가지 눈의 정확한 분포다.
| 단계 | DC | 성공률 (E=3) | (C=5) | (A=7) | (EX=8) |
|---|---|---|---|---|---|
| 쉬움 | 9 | 72.22% | 91.67% | 100% | 100% |
| 보통 | 12 | 27.78% | 58.33% | 83.33% | 91.67% |
| 어려움 | 15 | 2.78% | 16.67% | 41.67% | 58.33% |

### 3.3 보정치
1. 스탯·스킬·호감도·정보·기타 보정을 합산한다 [확정]. 영주 버프는 폐지 (D-142). 스탯은 변환된 수치를 그대로 쓰고 2개면 합산한다 (D-018, D-035).
2. 대항 판정은 강한 쪽 보정을 깎아 양측 차이를 최대 **8**로 맞춘다 → `dice.modifier_gap_cap` [임시값] (D-138).
3. 2d6 합의 차이는 최대 10. 상한 8에서 기적 없이도 약자 승리는 5/1296 = 0.386%다.

### 3.4 잭팟(기적)
자연값이 행운 구간이면 기적. ± 랭크는 문자 기준이며 기적 보정은 차이 상한 밖에서 더한다 [확정].
구간·보정은 2d6 전환 튜닝 [임시값] (D-138).
| 행운 랭크 | 기적 구간 | 발동 확률 |
|---|---|---|
| EX | 10, 11, 12 | 16.67% |
| A ~ B | 11, 12 | 8.33% |
| C 이하 | 12 | 2.78% |
- 구간은 `dice.miracle_range`, 보정은 `dice.miracle_bonus` = **3**. 면수가 줄어 기적 빈도가 높아지는 만큼 보정은 +5에서 +3으로 낮춘다.

### 3.5 운명점 재굴림 [확정] (D-010, D-038)
1. 굴림 후 운명점 1을 소모해 다시 굴린다. 재굴림 결과를 쓴다.
2. 초기값 **3** → `dice.fate_point_init` = 3
3. **게임 시작 전에 개수를 고른다** [확정] (D-081, D-095). 범위 **0 ~ 99** (D-127), 기본값 3, `+`/`-` 버튼으로 조정 → `dice.fate_point_min` = 0, `dice.fate_point_max` = 99. 많이 고른 대가: 없음 (Q-151 답에 언급 없음)
4. 게임 중에는 회복하지 않는다.
5. 한 판정에서 여러 번 재굴림할 수 있다 [확정] (D-081)
6. 재굴림은 **판정이 실패했을 때만** 묻는다 [확정] (D-119). 대항은 상대보다 낮을 때, 단독은 목표 미달일 때, 마력 공급은 실패·대실패일 때
7. 재굴림은 플레이어 서번트의 굴림에만 쓴다. 적 AI는 재굴림하지 않는다 (§3.6: 상대 굴림은 자동)

### 3.6 굴리는 주체 [확정] (D-073)
대부분의 판정은 유저가 직접 굴린다. 자동 처리 목록:
| 판정 | 처리 | 이유 |
|---|---|---|
| 내 서번트의 국면 판정 | **유저** | 핵심 연출 |
| 아침 마력 공급 판정 | **유저** | 중요한 순간이라 직접 굴린다 (D-145) |
| 낮 행동 판정 (정보 수집, 교류) | 자동 | 주사위·수치를 보이지 않고 운명점 재굴림도 없다 (D-145) |
| 도주 판정 | **유저** | |
| 기습 민첩 대항 | 자동 | D-109 |
| 상대 측의 모든 굴림 | 자동 | 상대 주사위는 연출만 |
| 적끼리 전투 전체 | 자동 | `combat.md` §8 |
| 국면 유형 추첨, 공격/방어 추첨 | 자동 | 판정이 아니라 추첨 |
| 명령 거부·배신 확률 판정 | 자동 | `affinity.md` §3.4 |
| 적 AI 이동, 3진영 이상 대진 추첨 | 자동 | |
| 강제 전투 대진 추첨 | 자동 | |

### 3.7 무작위 [확정]
모든 무작위는 시드 RNG 모듈을 통한다. 같은 시드 + 같은 입력 = 같은 결과.

### 3.8 방심: 폐기 (D-037)

## 4. 불변 조건 [확정]
- 어떤 스탯/보정 격차에서도 약자 승률 > 0% (§3.3 차이 상한으로 보장)
- 헤드리스 시뮬레이션 테스트로 검증한다

## 5. 참고: 2d6 대항 판정 확률 (기적 제외, 전수 계산)
| 보정 차이 | 약자 승 | 동점 |
|---|---|---|
| 0 | 44.37% | 11.27% |
| 3 | 15.90% | 8.02% |
| 6 | 2.70% | 2.70% |
| 8 이상 (상한 적용) | 0.386% | 0.772% |

## 6. 엣지 케이스
- 양쪽 기적이면 양쪽 +3.
- 상한 초과 시 강한 쪽 보정을 깎아 차이 8로 맞춘다.
- 운명점 0이면 재굴림 불가.

## 7. 예시 (테스트 케이스)
1. 기본 대항: 헤라클레스 정면 14.5 + 자연값 3 = 17.5, 메데이아 7 + 9 = 16 → 헤라클레스 승, 차이 1.5.
2. 기적: 코지로 민첩 7.5 + 자연값 11 + 기적 3 = 21.5, 헤라클레스 7 + 10 = 17 → 코지로 승, 차이 4.5.
3. 보정 25 vs 5 → 13 vs 5로 절삭. 강한 쪽 자연값 12에 기적이면 12 + 13 + 3 = 28.
4. 운명점 3에서 재굴림 → 2. 운명점 0에서 재굴림 → 거부.

## 8. 의존성
- 읽는 값: 스탯(`stats.md`), 스킬(`skills.md`), 호감도(`affinity.md`), 정보(`day-loop.md`), 영주(`combat.md`)
- 쓰는 값: 운명점, 이벤트 로그

## 9. 미정 사항
- 현재 판정 범위의 규칙은 구현됨. 스킬 보정은 다른 보정과 합산하고 차이 상한을 그대로 적용한다 (D-142, `skills.md` §6).
