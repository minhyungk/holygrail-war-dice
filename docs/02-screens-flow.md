## 3. 화면별 명세
각 화면은 아래 항목을 채운다. 빈 항목은 `[TBD]`.
`목적 · 진입 조건 · 표시 요소 · 입력 · 출력(상태 변화) · 전이 · PC 레이아웃 · 모바일 레이아웃 · 사용 데이터 · 엣지 케이스`

### S0_MAIN
| 항목 | 내용 | 상태 |
|---|---|---|
| 목적 | 게임 시작 진입점 | [확정] |
| 표시 요소 | 타이틀(소환대사), 소환, 촉매 소환, 통계 | [확정] |
| 통계 내용 | 우승자 비율. 구현 우선순위 낮음 | [확정] D-047 |
| 레이아웃 | PC/모바일 동일 | [확정] |

### S1_SUMMON
| 항목 | 내용 | 상태 |
|---|---|---|
| 목적 | 서번트를 얻는다 | [확정] |
| 입력 | 소환 방식 선택: 랜덤 소환 / 촉매 소환 | [확정] |
| 랜덤 소환 | 순수 랜덤 (성격 질문 방식은 보류) | [확정] |
| 촉매 소환 | 리스트에서 서번트를 골라 소환 | [확정] |
| 연출 | FGO처럼 마법진에서 빛이 나며 카드가 돌아 서번트 등장 → 풀 일러스트 + 소환대사 + 정보 표시 | [확정] |
| 공개 정보 | 전부: 스테이터스, 이름, 기본 스토리(FGO), 소환대사 | [확정] |
| 소환대사 | FGO 소환대사 사용 | [확정] |
| 적 진영 구성 | 적 마스터 × 서번트 조합은 랜덤 | [확정] D-045 |
| 운명점 | 게임 시작 전 추가 획득 가능. 방법 [TBD] | [확정] D-038 |
